## 十、结论写法

结论必须分成三层：

1. **工程验证**：代码测试、构建、离线评测和静态检查结果；
2. **内容验证**：标准答案、权威来源、人工事实判定和错误分析；
3. **用户验证**：两名真实用户的任务、时间、效果、反馈和限制。

不能用“系统测试通过”替代“真实用户认可”，也不能用“引用格式正确”替代“事实正确”。
