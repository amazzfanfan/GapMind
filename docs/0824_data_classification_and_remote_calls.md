# GapMind 数据分级、远程调用与留存规则

**版本**：v0.1（2026-08-24）
**适用分支**：`yx_dev`
**适用范围**：比赛 Demo、评测、开发环境和后续部署环境

本文把“哪些资料可以进入系统、哪些资料可以离开本机、保存多久、谁可以访问”写成可执行规则。当前文档是 P0 合规基线；正式提交前必须由项目负责人根据实际部署地址、参赛资料授权和比赛要求补齐空白项。

## 1. 数据分级

| 级别 | 示例 | 默认处理方式 | 是否允许远程调用 |
|---|---|---|---|
| L0 公开 | 已公开论文元数据、公开 DOI、公开摘要、公开机构信息 | 可导入、可索引、可用于演示 | 允许，但仍需记录供应商和版本 |
| L1 项目公开 | 项目自建提示词、脱敏 Gold 问题、公开论文的本地切片 | 可进入比赛 Demo 和评测 | 仅在配置了对应服务且完成调用记录时允许 |
| L2 项目内部 | 未发布的研究计划、人工批注、用户测试记录、内部方案 | 默认仅本地处理，最小权限访问 | 禁止默认发送；如确需发送，必须由用户逐次确认并记录范围 |
| L3 敏感/受限 | 未授权全文、个人身份信息、联系方式、实验原始数据、密钥、受限数据集 | 不进入公共 Demo，不提交仓库，不写入日志 | 禁止远程发送；不应上传到比赛环境 |

## 2. 远程服务清单与传输边界

| 服务 | 当前用途 | 可能发送的数据 | 默认策略 | 需要留下的证据 |
|---|---|---|---|---|
| DeepSeek/OpenAI-compatible LLM | Workspace Chat、Discover、计划/代码草稿 | 用户问题、受控检索上下文、结构化提示词 | L0/L1 可用；L2 需显式确认；L3 禁止 | provider、model、时间、输入摘要/哈希、输出状态、错误 |
| SiliconFlow Embedding | 文本向量化 | 文本片段 | 仅处理已授权资料；L2 需确认 | embedding model、维度、批次、失败原因 |
| SiliconFlow Reranker | 检索重排 | 查询与候选片段 | 与 Embedding 同级 | reranker 版本、是否降级 |
| Semantic Scholar | 外部新颖性检索 | 研究轴、关键词、论文 ID | 只发送最小查询，不发送全文和用户身份 | query、时间、返回数量、限流/错误 |
| Ollama SSH 隧道 | Gap Board 垂类抽取 | 论文文本或研究空白输入 | 仅在项目控制的隧道内使用；不启用本机 Ollama 覆盖隧道 | provider、model、digest、参数、连接状态 |

Gap Board 的远程回退必须同时满足服务端开关 `GAP_EXTRACTOR_REMOTE_ENABLED=true` 和本次请求的材料传输同意；前端不能静默打开该开关。

## 3. 必须禁止的泄漏路径

- 不把 API key、Authorization、Cookie、完整请求头写入日志、截图、PPT 或提交包。
- 不把未经授权的 PDF、`storage/`、`data/chunks/`、用户测试原始记录加入 Git。
- 不把完整 L2/L3 文本拼进外部检索 query；外部检索只携带最小化、可解释的研究轴和关键词。
- 不把模型原始输出直接当作事实；输出必须带 AI/未确认标记，并通过来源或人工确认状态进入后续流程。
- 不用真实用户姓名、邮箱、单位和联系方式作为演示数据；报告只保留角色、任务和匿名编号。

## 4. 留存与删除

当前比赛版本先采用以下最小规则，最终提交前由负责人填写实际部署值：

| 数据 | 默认留存 | 删除/清理方式 | 负责人 |
|---|---|---|---|
| 公开论文快照 | 比赛复现期间 | 按快照版本整体替换 | 项目负责人 |
| 用户上传 PDF | 仅保留演示/评测所需期间 | 删除文件、切片、向量和关联索引 | 项目负责人 |
| Chat 消息与证据 | 复现和问题定位所需期间 | 按 workspace 软删除，再清理物理存储 | 项目负责人 |
| 运行日志 | 不超过部署所需周期 | 脱敏后轮转 | 运维负责人 |
| 用户测试记录 | 报告完成且授权范围内 | 原始记录与脱敏记录分离保存 | 评测负责人 |

待补字段：实际保存天数、备份周期、备份加密方式、删除验证记录、部署服务器地域和供应商数据处理条款。

## 5. 用户提示与同意文案

上传或调用远程模型前，界面/操作手册至少要能让用户知道：

> 本次操作可能将输入问题及系统选取的论文片段发送至已配置的模型/检索服务。请勿上传未授权、含个人信息或受限材料。系统会标注 AI 生成和未确认内容；远程服务不可用时，结果可能为空、降级或需要重试。

Gap Board 还需单独显示：

> 研究空白抽取默认使用项目配置的 Ollama 服务。若开启远程回退，必须再次确认允许发送本次文本；拒绝后只使用本地服务或返回不可用状态。
